#Comandos

- status = muestra el estado del repositorio
- init = inicia un repositorio, puede ser catastrófico usar el comando en un repositorio existente porque se puede perderse la configuración de este, eliminarse el repositorio y crearse uno nuevo o generarse riesgo en repositorios remotos
- add = agrega todos los archivos del repositorio
- commit = registra los cambios preparados (como el uso de git add)
- log = muestra el historial de commits
- push = sube los cambios al repositorio remoto
- pull = descarga los cambios del repositorio remoto, es importante al trabajar equipo porque sincroniza tu repositorio local con el repositorio remoto actualizando el código, evitando problemas/fallas en el repositorio y permitiendo integrar los cambios de otros colaboradores
- clone = permite clonar un repositorio remoto

#Qué es un Markdown

Es un lenguaje (estándar en GitHub) de texto plano eficiente para la creación de documentos, textos o READMEs en los repositorios de GitHub
