#Comandos

- Status = Para ver el estado del repositorio

- Init = Inicializa un repositorio, puede ser catastrofico usar init en un repositorio que ya existe debido a que puede cambiar la configuración del repositorio, hacer que pierda datos el repositorio remoto y que se confundan los repositorios si no usas .git.

- Add = Agrega todos los archivos de la carpeta

- Commit =  Registra permanentemente todos los cambios del comando git add

- Log =  muestra el historial de commits de un repositorio

- Push = sube los commits que hay en la rama local del repositorio al repositorio remoto

- Pull = descarga y fusiona los cambios recientes del repositorio remoto, es importante ejecutarlo al trabajar en equipo por si otros colaboradores hicieron cambios y querés traerlos a tu máquina o tu repositorio local está desactualizado con el remoto o querés evitar conflictos trabajando con la versión más reciente del proyecto

- Clone = crea una copia lcoal completa de un repositorio

#¿Qué es un Markdown?

Es un lenguaje (estándar en GitHub) para dar formato al texto que quieras meter en un archivo de un repositorio como un documento README, etc.
